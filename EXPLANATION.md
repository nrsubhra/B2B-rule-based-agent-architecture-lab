# Supervisor-facing summary

We built a controlled B2B procurement environment where the same vendor-selection problem can be routed through different organizational AI structures. Vendor attributes and diagnostic facts are synthetic and researcher-controlled. The complete vendor record is evaluated using a pre-specified organizational utility function to create a design-implied benchmark. We then distribute the same information through Single, Pipeline, Parallel, Shared Memory, or Supervisor systems and measure final choice, regret, and critical-fact retention.

The first empirical study should manipulate only architecture and centralized vs fragmented information. Goal conflict and specialization remain later-study extensions. The rule-based agents are an apparatus-validation layer, not the final behavioral model. Once the design is stable, the same environment and measurement schema can be transferred to Claude/GPT agents.
